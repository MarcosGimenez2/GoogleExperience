# 🚀 GoogleExperience

### Explore o universo de tecnologias do Google.

O **GoogleExperience** é um projeto web desenvolvido para apresentar o ecossistema de tecnologias do Google em uma interface moderna, interativa e responsiva. Explore ferramentas de busca, inteligência artificial, computação em nuvem, análise de dados e muito mais.

🌐 **Demo online:** *em breve*

📦 **Repositório:** [GitHub — GoogleExperience](https://github.com/MarcosGimenez2/GoogleExperience)

---

## ✨ Funcionalidades

- 🎨 **Tema claro e escuro:** alterne entre os temas da interface.
- 🔎 **Ecossistema Google:** conheça ferramentas e tecnologias como Google Search, Gemini e TensorFlow.
- ☁️ **Tecnologias em destaque:** explore soluções de nuvem, dados e sistemas operacionais.
- 🕵️ **Google Detective:** uma experiência interativa de desafio.
- 📱 **Interface responsiva:** layout adaptável a diferentes tamanhos de tela.
- 🧭 **Navegação por seções:** explore o conteúdo de forma organizada.

## 💻 Como executar localmente

### Pré-requisitos

- Node.js e npm instalados.
- Angular CLI instalado ou disponível pelo projeto.

### Instalação

1. Clone o repositório:

   ```bash
   git clone https://github.com/MarcosGimenez2/GoogleExperience.git
   ```

2. Entre na pasta do projeto:

   ```bash
   cd GoogleExperience
   ```

3. Instale as dependências:

   ```bash
   npm install
   ```

4. Inicie o servidor de desenvolvimento:

   ```bash
   npx ng serve
   ```

5. Acesse no navegador:

   `http://localhost:4200`

## 🏗️ Build de produção

Para gerar a versão de produção:

```bash
npm run build
```

O diretório gerado depende da configuração de build definida no `angular.json`.

## 🚀 Deploy

O projeto será publicado utilizando o [Vercel](https://vercel.com/), com integração ao repositório do GitHub.

## 🎯 Objetivo do projeto

Explorar o desenvolvimento de interfaces com Angular, praticar estilização com CSS e apresentar tecnologias populares do ecossistema Google em uma experiência visual e interativa.
